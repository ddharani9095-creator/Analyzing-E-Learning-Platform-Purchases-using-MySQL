This project analyzes an Online Learning Platform database using SQL to generate business insights from learner, course, and purchase data. The project demonstrates SQL skills such as joins, aggregations, subqueries, CTEs, CASE expressions, views, and NULL handling to answer real-world business questions.
🎯 Objectives
Analyze learner purchasing behavior.
Calculate total revenue and learner spending.
Identify top-performing courses and categories.
Find courses with no purchases.
Classify learners based on spending.
Build reusable SQL views for reporting.
🛠️ Technologies Used
MySQL
SQL
DBMS
📂 Database Schema

The project consists of three tables:

Learners – Learner information
Courses – Course details and pricing
Purchases – Purchase transactions
